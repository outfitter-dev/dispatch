# dispatch Skills

First-party skills for using dispatch:

- [`dispatch`](dispatch/SKILL.md) - operate the dispatch daemon, CLI, MCP surface, lanes,
  and triggers.
- [`dm`](dm/SKILL.md) - send a short dispatch-backed "dispatch message" to an owned lane.

The Codex plugin at [`../plugins/dispatch`](../plugins/dispatch) exposes this same skills
tree through its `skills` link, so skill behavior has one source in this repo.
